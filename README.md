# BookHaven

A modern online bookstore platform for browsing, searching, and purchasing books. It offers a seamless and responsive experience across desktop and mobile devices.

## Features

- **User Authentication** - Sign up, sign in, and account management
- **Book Browsing** - Browse and search for books with filters
- **Shopping Cart** - Add/remove books and manage cart
- **Wishlist** - Save favorite books for later
- **Email Verification** - Secure email verification during signup
- **Password Reset** - Recover account access with email
- **Responsive Design** - Works on desktop and mobile devices
